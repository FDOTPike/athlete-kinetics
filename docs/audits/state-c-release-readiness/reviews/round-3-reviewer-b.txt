Discrepancies 1-3 are the ones that matter. #1 is a 6.1 row labelled directly observed, dated today,
whose numbers are wrong and whose closing assertion is false against the document's own declared
counts. #2 is a limitations bullet that denies a review round the document itself records in detail.

architecture review, then immediately undercut by offering an agent's implementation report as the
owner's ratification record.

None of these is a progression-engine error — the progression analysis, the isPurelyBodyweight
fan-out, the ladder-floor regression, the bar-of-8 fallback, the State A/State C dose comparison and
the U1 row-by-row re-derivation are all correct and, in the case of the weighted-calisthenics
improvement, commendably even-handed. But #1 and #3 are state-provenance and attribution
discrepancies, and the charter's approval bar is zero.

Suggested minimal fixes: correct the CR-03 row to B 6 / 121 (or delete it as redundant with the
"Corpus totals" row); rewrite the 6.3 bullet to match 6.2's register and re-scope "What a round-2
reviewer should attack first" to round 3; re-cite or reword 3.1's ratification sentence; add the
verify_pipeline.mjs:514-517 citation to closeout 2.1; and add the permitted open-episode delete to
