# F — Flaw-Detection Operator

## Closed-Form Formulas

Let \( W = 21 \) trailing calendar days, indexed \( i = 0,1,\dots,20 \) where \( i=0 \) is the oldest day and \( i=20 \) is the current day \( t \).  
For each movement pattern \( p \in \text{MOVEMENT\_PATTERNS} \), define the following daily arrays from the window:

- \( n_p(i) \) = number of sets logged for pattern \( p \) on day \( i \) (0 if no session).
- If \( n_p(i) > 0 \):
  \[
  e_p(i) = \frac{1}{n_p(i)}\sum_{\text{sets on day } i} \bigl(\text{rpe\_actual} - \text{target\_rpe}\bigr)
  \]
  \[
  w_p(i) = \frac{1}{n_p(i)}\sum_{\text{sets on day } i} \frac{1}{\max\!\bigl(1,\; \text{effective\_load\_kg} / \max(\text{base\_load\_kg},\,0.01)\bigr)}
  \]
  If base_load_kg ≤ 0 the ratio is taken as 1.
- \( j_p(i) \) = maximum severity over niggle rows on day \( i \) with `region ∈ PATTERN_JOINTS[p]`, or 0 if none.

### 1. Exponential Moving Sum (EMA)
Choose decay factor \( \lambda \in (0,1) \).  
Weight for day \( i \): \( \omega_i = \lambda^{20-i} \).

Normalization constant:
\[
S_{\max} = \sum_{k=0}^{20} \lambda^k = \frac{1-\lambda^{21}}{1-\lambda}
\]

### 2. Deficit / Headroom Accumulation
\[
\begin{aligned}
P_p &= \sum_{\substack{i=0 \\ e_p(i)>0}}^{20} \omega_i \cdot w_p(i) \cdot \min(e_p(i),\, E_{\max}) \cdot \max\!\bigl(0,\; 1 - \frac{j_p(i)}{J_{\max}}\bigr) \\[4pt]
N_p &= \sum_{\substack{i=0 \\ e_p(i)<0}}^{20} \omega_i \cdot w_p(i) \cdot \min(|e_p(i)|,\, E_{\max})
\end{aligned}
\]
\( E_{\max} \) caps the RPE error magnitude; \( J_{\max}=10 \) (max niggle severity).

### 3. Base Deficit Score
\[
D_p = P_p - N_p, \qquad 
D_{\text{norm}} = \frac{D_p}{E_{\max} \cdot S_{\max}}
\]
Apply deadband:
\[
\phi_{\text{base}} = \begin{cases}
0, & |D_{\text{norm}}| < \delta \\
D_{\text{norm}}, & \text{otherwise}
\end{cases}
\]

### 4. Trend Signal
\[
e_{\text{old}} = \frac{1}{|\{i\in[0,6]\mid n_p(i)>0\}|}\sum_{\substack{i=0\\ n_p(i)>0}}^{6} e_p(i), \quad
e_{\text{recent}} = \frac{1}{|\{i\in[14,20]\mid n_p(i)>0\}|}\sum_{\substack{i=14\\ n_p(i)>0}}^{20} e_p(i)
\]
(empty sets → 0).

\[
t_p = \tanh\!\left(\frac{e_{\text{recent}} - e_{\text{old}}}{T_{\text{scale}}}\right)
\quad \text{with } \tanh(x) = \frac{e^{2x}-1}{e^{2x}+1}
\]

### 5. Final Flaw Score
\[
\phi_p = \operatorname{clamp}\!\bigl(w_{\text{base}}\cdot\phi_{\text{base}} + w_{\text{trend}}\cdot t_p,\; -1,\; 1\bigr)
\]
Round to 4 decimal places using `round4`.

### 6. Observations & Classification
\[
\text{obs}_p = \bigl|\{i \mid n_p(i) > 0\}\bigr|
\]
If \( \text{obs}_p < \text{MIN\_OBSERVATIONS} \) → `flawClass = 'neutral'`.  
Else if \( \max_i j_p(i) \ge \text{triageMin}(trainingAge) \) → `'caution'`.  
Else if \( \phi_p \ge \theta_{\text{def}} \) → `'capacity_deficit'`.  
Else if \( \phi_p \le -\theta_{\text{headroom}} \) → `'latent_headroom'`.  
Else → `'neutral'`.

# u_{t+1} — Control Action Operator

## Closed-Form Mapping

Inputs: `FlawReport`, `UserProfile` (containing `trainingAge`, `objective`, `base_rpe_cap`, `macroPhase`), and optionally the set of patterns for a specific day to produce a daily `AdjustmentVector`.

### 1. Per-Pattern Raw Corrections

Let \( \phi = \phi_p \). Determine raw deltas using deadband and thresholds:

| Condition                          | `raw_dRpe` | `raw_dSet` | `raw_dLoad_target` | `raw_prefBias` |
|------------------------------------|------------|------------|-------------------|----------------|
| `flawClass == 'caution'` OR any restrictive guardrail OR halt | – | – | – | – |
| (see safety override below)        |            |            |                   |                |
| \(|\phi| < 0.15\)                  | 0          | 0          | 1.00              | 0              |
| \( \phi \ge 0.4 \)                 | –0.5       | –1         | 0.95              | –1             |
| \( 0.15 \le \phi < 0.4 \)         | –0.5       | –1         | 1.00              | –1             |
| \( \phi \le -0.4 \)               | +0.5       | +1         | 1.05              | +1             |
| \(-0.4 < \phi \le -0.15\)         | +0.5       | +1         | 1.00              | +1             |

If `flawClass == 'caution'` or `globalGuardrail` is restrictive (`load_multiplier<1` or `set_delta<0` or `rpe_cap_max<10`) or any loaded joint for pattern has severity ≥ `triageMin` or `halt` true, then force:
- `dRpe_p = min(0, raw_dRpe)`
- `dSet_p = min(0, raw_dSet)`
- `dLoad_target = min(1.0, raw_dLoad_target)`
- `prefBias_p = min(0, raw_prefBias)`

Otherwise `dRpe_p = raw_dRpe`, etc.

### 2. Snap to Literal Domains

- `dLoad_p = snapToLiteral(dLoad_target, LOAD_MODIFIER_LITERALS)` (nearest, tie → lower).
- `dSet_p = clamp(raw_dSet, -1, 1)` (already integer).
- `dRpe_p = clamp(raw_dRpe, -0.5, 0.5)` and further ensure that for each week \( w \in \{1,2,3\} \),
  \[
  \text{target\_rpe}_{p,w} = \operatorname{clamp}\!\bigl( \text{SCHEMES[objective].rpeWave}[w] + \text{PHASE\_MODS[macroPhase].rpe} + dRpe_p,\; 5.0,\; \text{base\_rpe\_cap} \bigr)
  \]
  Round to 0.5.
- `prefBias_p = raw_prefBias` (already ∈ {−1,0,1}).

### 3. Global Volume Budget

Let \( \mathcal{P}^+ = \{ p \mid dSet_p > 0 \} \).  
If \( \sum_{p\in\mathcal{P}^+} dSet_p > \text{MAX\_ADDED\_SETS} \), sort \( \mathcal{P}^+ \) by \( \phi_p \) ascending (most headroom first) and set `dSet_p = 0` for all but the first `MAX_ADDED_SETS` patterns.

### 4. Daily AdjustmentVector Projection

For a given day with scheduled patterns `DayPatterns ⊆ MOVEMENT_PATTERNS`:
\[
\begin{aligned}
\text{load\_mod} &= \min_{p\,\in\,\text{DayPatterns}} dLoad_p \quad (\text{default } 1.0) \\
\text{set\_mod}  &= \min_{p\,\in\,\text{DayPatterns}} dSet_p  \\
\text{rpe\_cap}  &= \min_{p\,\in\,\text{DayPatterns}} \operatorname{clamp}\!\bigl( \text{base\_rpe\_cap} + dRpe_p,\; 5.0,\; 10.0 \bigr)
\end{aligned}
\]
Then `rpe_cap = snapToLiteral(roundToHalf(rpe_cap), RPE_CAP_LITERALS)`.  
`coaching_cue` is generated deterministically from the pattern with maximal \(|\phi_p|\) and its flaw class (e.g., “Reduce effort on hinge – persistent capacity deficit.”).  
Finally apply `clampAdjustment` (idempotent).

# Invariant List (Machine-Checkable Guarantees)

1. **Determinism**  
   Every arithmetic operation uses only the permitted primitives and fixed rounding rules (`round2`, `round4`, `roundToHalf`). No clock, random, or order‑dependent reduction. Same persisted inputs → byte‑identical `FlawReport` and `ControlAction`.

2. **Monotone-Conservative under Flags**  
   If any `Guardrail` is restrictive (`load_multiplier < 1`, `set_delta < 0`, `rpe_cap_max < 10`) or any loaded joint has niggle severity ≥ `triageMin`, the control action never increases load, sets, or RPE for the affected patterns. It may only reduce them or leave them neutral.

3. **Domain Closure**  
   - `dLoad_p` is snapped to one of `LOAD_MODIFIER_LITERALS`.  
   - `dSet_p` ∈ {−1, 0, 1} (subset of `SET_MODIFIER_LITERALS`).  
   - Daily `rpe_cap` is rounded to nearest 0.5 and snapped to `RPE_CAP_LITERALS`.  
   - The final `AdjustmentVector` passes `clampAdjustment` idempotently.

4. **Halt Supremacy**  
   If `halt` is true, all corrections become neutral (`dLoad_p = 1.0`, `dSet_p = 0`, `dRpe_p = 0`, `prefBias_p = 0`) — no block change is emitted.

5. **Bounded Authority per Block**  
   - Total positive set additions across all patterns ≤ `MAX_ADDED_SETS` (2).  
   - Load modifier changes by at most one literal step (0.05) away from 1.0.  
   - RPE target changes by at most ±0.5.  
   - Per-pattern set change ≤ ±1.  
   This ensures the controller cannot windup or oscillate; the existing monotone clamps further limit any daily projection.

6. **Volume Bifurcation**  
   Corrections act on the prescription (target RPE, sets, load modifier) and use effective tonnage only for condition‑weighting inside F. The raw `mech_daily` tonnage / ACWR pipeline is never altered.
