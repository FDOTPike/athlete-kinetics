## Numeric decision record

Every proposed numerical default above is either a sourced educational value (R01), an existing code choice (R08/R11/R13 with the audit's exact line inventory), or explicitly H02 pending. R03 alternative dose, R04 lookback, and R07 scale require Francis ratification; their intended outcome, adult population, limitations, low dose confidence and pre-implementation review are specified in H02. R12 rejects a numerical fuzzy-dedup threshold. Example schedules and clinician values in the docket are fixtures supplied to exercise the contract, never defaults.

No new sport progression percentage, first-week weight-loss dose, readiness threshold, clinician HR threshold, fluid/salt amount, monitoring freshness limit or symptom severity threshold is proposed as an executable validated rule.
