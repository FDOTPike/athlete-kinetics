## Tooling note for future Cowork sessions (important)

The Cowork↔Windows file bridge in THIS session delivered Edit-tool writes to
PRE-EXISTING files truncated and/or replayed them late (session-CREATED files
were always intact). Recovery that worked: `git show HEAD:file > file`
restores + scripted python re-patch + gate re-run; git index rebuilds via
`rm .git/index && git read-tree HEAD`. Rule of thumb adopted: in Cowork,
treat bash as the write path for files that pre-date the session; use file
tools freely for new files. On-device/VS Code work is unaffected.
